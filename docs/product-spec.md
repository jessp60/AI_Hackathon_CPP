# Product Spec: Insight Quest MVP

## Product Goal

Increase student attendance at Insight Association events by turning participation into progression, collection, and exploration.

## Success Metrics

- event attendance rate
- repeat attendance within 30 days
- number of students with at least one check-in
- average events attended per active user
- number of unlocked cities per active user
- weekly active users

## Target Audience

- college and university students
- student organization members
- event organizers who want better participation

## Player Motivation

- progression: level up the avatar
- collection: earn badges and cosmetics
- identity: show off a unique character
- exploration: unlock new cities
- consistency: maintain attendance streaks

## Core Screens

### Home
- next event
- current level and XP
- quick access to avatar and map

### Calendar
- monthly event view
- filters by category or campus

### Event Details
- event info
- RSVP
- check-in method
- rewards preview

### Avatar
- character preview
- level
- unlocked cosmetics and badges

### Map
- unlocked cities
- locked city silhouettes
- city rewards

### Profile
- attendance history
- badge collection
- stats and streaks

## Game Economy

### Rewards
- XP for attendance
- bonus XP for streaks
- coins for cosmetics
- badges for milestones

### Example Progression
- attend 1 event: starter badge
- attend 3 events: level 2 outfit
- attend 5 events: accessory unlock
- unlock 3 cities: traveler badge

## Anti-Abuse Rules

- one reward claim per event per user
- limited check-in window
- organizer-generated dynamic QR code or rotating event code
- optional admin review for suspicious check-ins

## Privacy Rules

- request location only for city unlock features
- default to coarse location when possible
- do not show exact user travel history publicly
- let users disable location-based rewards

## MVP Risks

- fake event attendance if verification is weak
- user drop-off if progression feels too slow
- privacy concerns if location messaging is unclear

## Risk Mitigation

- use QR or event code for attendance verification
- keep first three rewards easy to earn
- make location opt-in and explain the benefit clearly

## Recommended MVP Scope

Keep the first version lightweight:

- 2D avatar customization instead of a full animated 3D world
- location-based city unlocks, not live map gameplay
- event check-in rewards, not combat or complex mini-games

This gives you a polished student engagement app with game mechanics, which is much faster to build and test.
